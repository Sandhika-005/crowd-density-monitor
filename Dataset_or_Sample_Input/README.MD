# Dataset

Proyek ini menggunakan **ShanghaiTech Crowd Counting Dataset – Part B** untuk melatih dan mengevaluasi model penghitung orang.
Source: https://www.kaggle.com/datasets/tthien/shanghaitech

Folder `images` berisi foto kerumunan. Folder `ground_truth` berisi file `.mat` dengan anotasi titik lokasi kepala untuk setiap foto.
dataset di folder ini merupakan sample  yang diambil dari data test pada **ShanghaiTech Crowd Counting Dataset – Part B**
